# Свидетельство задачи № 004 — 04.11.2026

Реализована локальная демонстрация прохождения трёх вопросов. Варианты radio/checkbox, точный по локальному monotonic clock отсчёт, блокировка просрочки и повтора, оценка через shared, объяснения, переходы, итоги и перезапуск. Адаптивные стили, нативная семантика полей и перенос фокуса.

[Алгоритм и объём](../../../tasks/004-quiz-player-ui.md). [Браузерный протокол](../../../testing/004-ui-check-2026-11-04.md). [Фактические замеры Chrome](004-browser.txt). Правильные ответы присутствуют в bundle только для демонстрации; настоящий серверный протокол не реализован.

Предварительные проверки: 16 frontend-тестов, lint, typecheck и сборка прошли; затем добавлен отдельный тест пустой программной отправки формы. Зависимости установлены offline из имеющегося store, добавлена только workspace-зависимость @quiz/shared. Публичные контракты shared и код API не менялись.

Все перечисленные команды завершились с exit=0. HTTP-тест существующего API выполнялся с разрешением на временный localhost-порт. Вывод команд — [004-checks.txt](004-checks.txt).

Браузер: начальный экран измерен на 320/375/430/768/1280 px без горизонтального переполнения; варианты высотой 60 px. Визуально осмотрены фактические скриншоты начальных экранов на 320/375/1280 и результата/итогов на 375. Подтверждены клавиатурный выбор/отправка/переходы, реальный пятисекундный timeout, итоги 2500/3000 и перезапуск. Reduced motion даёт transition-duration=0s. Это автоматизированный проход и визуальный осмотр скриншотов, а не ручная проверка пользователем на телефоне.

Неисправленных ошибок по выполненным проверкам нет. Две первоначальные ошибки браузерного сценария относились к передаче клавиш CDP; исправление сценария и его успешный повтор описаны в отдельном протоколе.
