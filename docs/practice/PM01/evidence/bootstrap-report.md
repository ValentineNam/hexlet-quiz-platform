Воспроизведение: переключить Node по README, установить pnpm указанной версии, выполнить команды из checks.txt. В этой сессии PATH дополнен /private/tmp/node-v24.22.2-darwin-arm64/bin и /private/tmp/quiz-pnpm/node_modules/.bin; store-dir установлен в /private/tmp/quiz-pnpm-store, чтобы не менять пользовательские каталоги.

- Монорепозиторий apps/web, apps/api, packages/shared.

## Фактические ошибки и ограничения

1. Первые сетевые запросы curl/pnpm внутри песочницы завершились ENOTFOUND. С разрешением на сеть загрузка и установка прошли.
2. Первый HTTP-тест завершился EPERM при открытии порта; повтор вне песочницы прошёл. Тест использует временный порт на 127.0.0.1 и закрывает приложение в finally.
3. docker compose config недоступен: Docker CLI не обнаруживает compose. Установленный docker-compose config --quiet прошёл с тестовым значением POSTGRES_PASSWORD. Системные настройки Docker не менялись.
4. При первоначальной проверке docker info вне песочницы сообщил Cannot connect to the Docker daemon; тогда PostgreSQL не запускалась. Позднее 04.11.2026 пользователь подтвердил успешную инфраструктурную проверку: Colima 0.10.1, Docker Engine 29.2.1, PostgreSQL 17.6 Alpine, контейнер healthy, сервер принимает подключения на 127.0.0.1:5432. См. [подтверждение PostgreSQL](postgresql-verification.md). Подключение backend к БД пока не проверялось.
5. pnpm сообщает deprecated для eslint 9.39.1 и whatwg-encoding 3.1.1, а также пропущенный необязательный postinstall @nestjs/core (баннер поддержки проекта). Это не мешает проверкам. Разрешён build-скрипт esbuild. Аудит уязвимостей не выполнялся; выбранные версии не заявляются последними.
6. CI настроен, но GitHub Actions не запускался: отправка в GitHub не выполнялась.
7. Мобильные CSS-правила реализованы. Позднее 04.11.2026 пользователь подтвердил визуальную проверку в Chrome DevTools, эмуляция iPhone SE, 375 × 667 px: заголовок и текст отображаются полностью, переносы корректны, карточка имеет отступы, видимых перекрытий и обрезания нет. [Протокол](../../../testing/frontend-manual-2026-11-04.md), [скриншот](frontend-mobile-375-2026-11-04.png). Другие разрешения, реальные смартфоны, интерактивность и нагрузка не проверялись.
