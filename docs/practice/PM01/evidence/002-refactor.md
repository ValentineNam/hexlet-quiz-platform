# Задача № 002: ограничение обхода массива — 04.11.2026

Рефакторинг выполнен только по замечанию об обходе заведомо недопустимого массива вариантов.

## Изменение алгоритма

После проверки Array.isArray выполняется проверка длины. При длине вне 2–6 добавляется одна ошибка OPTION_COUNT / options, и ветка вариантов завершается без чтения элементов, нормализации вариантов, выделения множества id для элементов или подсчёта правильных ответов. Ошибки остальных полей сохраняются. Обход вариантов выполняется только для длины 2–6.

Работа с заведомо недопустимым массивом занимает O(1) по его длине. Публичные типы и формат результата не менялись. Валидация корректных вопросов работает по прежнему алгоритму. Документированное ограничение по произвольным Proxy/getter-объектам сохранено; их поддержка не добавлялась.
