## Обнаруженные ошибки среды и исправления

1. CI=true по умолчанию включает frozen install: после изменения manifests потребовалось явное обновление lockfile через --no-frozen-lockfile. Итоговая frozen-команда запускается заново, обновление не выдаётся за frozen-проверку.
2. Сетевые загрузки внутри песочницы получили ENOTFOUND; зависшая попытка установки остановлена, повтор с разрешённой сетью успешен.
3. Генерация Prisma получила EPERM при обновлении cache движка в домашнем каталоге; повтор с разрешением прошёл. Глобальная версия Node не менялась.
4. Prettier не определяет парсер .env.example при явном указании файла. Поддерживаемые файлы отформатированы; содержимое примера env без реальных секретов. Финальный format:check — отдельный результат.

5. Итоговый lint обнаружил no-control-regex в проверке NUL. Вместо регулярного выражения для NUL используется includes(String.fromCharCode(0)); проверка изолированных суррогатов сохранена. После исправления полный набор проверок повторён успешно.

## Ограничения

API доступен только на 127.0.0.1 и включается ENABLE_QUIZ_API=true; по умолчанию маршруты отсутствуют. Нет авторизации/owner, поэтому нельзя объявлять эту реализацию готовым публичным CRUD собственных квизов. Нет снимков/истории, WebSocket, комнат, UI-редактора, CORS-настройки для будущего браузерного клиента, загрузки медиа или деплоя. /health — liveness, а не DB-readiness. Прямые SQL-записи не защищены от межстрочных нарушений количества вариантов/правильных ответов. Перед сохранением через API эти правила проверяются существующим shared-валидатором.

Стандартные проверки не требуют БД; отдельные DB-тесты требуют явного TEST_DATABASE_URL на \*\_test и заранее применённой миграции. CI service настроен, но удалённый Actions не запускался. Код и таблицы авторизации — следующая отдельная задача; не реализованы сейчас. Коммиты и push не выполнялись.
