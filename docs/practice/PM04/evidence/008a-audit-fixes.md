## Реальная модификация

ReadinessService возвращает общий result без async wrapper, создаёт deadline до запуска raw операции, устанавливает одну пару handlers. False кешируется до фактического settle, после чего identity guard освобождает state. Sync throw/rejection скрыты. SQL/таймауты250/750/1000 сохранены.

Shutdown-watchdog только наблюдает SIGTERM/SIGINT перед native Nest hooks; сам второй close не запускает. Его5-секундный unref timer охватывает всю цепочку async hooks, не ждёт Prisma и при зависании вызывает exit1. Обычный re-signal Nest не перехватывается повторно благодаря once listeners. Ошибка Prisma disconnect обезличивается. Предел5000 и допуск теста1500 документированы, завершение не зависит от возвращения PG.
