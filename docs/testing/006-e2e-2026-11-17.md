# Протокол сквозного тестирования № 006

Фактическая дата: 17.11.2026, Europe/Moscow. Исходный HEAD 19833ed + незакоммиченные изменения № 006. Среда: macOS, Node 24.22.2, pnpm 10.34.9, Chrome/157.0.8103.79 headless через Chrome DevTools Protocol. Использован установленный Chrome и доступный в окружении Python websockets; зависимости проекта не добавлялись. Это автоматизированный браузерный прогон с последующим просмотром сохранённых изображений, не ручное тестирование на смартфонах.

## Подготовка и изоляция

1. Первая попытка остановилась до создания контейнера: порт API 3000 занят. Чужой процесс не завершался.
2. Запущен отдельный одноразовый postgres:17.6-alpine, БД quiz006_test, случайный пароль только в окружении, случайный порт на 127.0.0.1, без существующего volume. pg_isready успешен.
3. Применена миграция № 005. Четыре существующих integration-теста прошли с реальным PrismaClient, без mock.
4. API собран и запущен Node-процессом с ENABLE_QUIZ_API=true на свободном loopback-порту; Vite запущен на отдельном порту с согласованным QUIZ_API_PORT. /health и Vite ответили 200. Chrome запущен с отдельным временным профилем.

## Повторение разработчиком

Настроить БД и миграцию по README, запустить ENABLE_QUIZ_API=true pnpm dev (или согласовать PORT и QUIZ_API_PORT). Повторить шаги 1–9; проверять Network по префиксу /api, а SQL — только в своей тестовой БД. Четыре DB-теста требуют TEST_DATABASE_URL на отдельную \*\_test БД. Сценарии ошибок и сетевого отказа покрыты UI-тестами с fetch mock; реального отключения БД во время браузерного сценария не выполнялось. Результат production-сборки проверяется отдельно build, production-развёртывание не проверялось.
